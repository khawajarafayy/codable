================================================================================
                        CODABLE PROJECT SUMMARY
================================================================================

CODABLE is a comprehensive Java learning platform that combines an online 
code IDE with interactive learning features. The project consists of two 
main parts: a React frontend and an Express.js backend.

================================================================================
                        CODABLE BACKEND (codable-backend)
================================================================================

TECHNOLOGY STACK:
- Node.js with Express.js
- MongoDB with Mongoose ODM
- JWT for authentication
- WebSocket for real-time code execution
- bcryptjs for password hashing

KEY FEATURES:

1. USER AUTHENTICATION
   - User registration (name, email, password)
   - User login with JWT token generation
   - Password hashing with bcrypt
   - Role-based access (student, instructor)
   - Token-based authentication middleware

2. STUDENT PROFILE MANAGEMENT
   - Create, read, update, delete student profiles
   - Profile fields: fullName, avatar, bio, location, socialLinks
   - Auto-creation of profile on user registration
   - Membership tiers: free, pro, premium
   - Membership upgrade functionality

3. CODE EXECUTION (via WebSocket)
   - Real-time Java code compilation and execution
   - WebSocket server at /ws/code path
   - Uses local javac and java commands
   - Creates temporary directories for each session
   - Handles stdin/stdout/stderr
   - Supports stopping execution
   - Automatic cleanup of temporary files

4. API ENDPOINTS:
   - POST /auth/signup - Register new user
   - POST /auth/login - Login user
   - GET /student/profile - Get student profile
   - POST /student/profile - Create profile
   - PUT /student/profile - Update profile
   - DELETE /student/profile - Delete profile
   - PUT /student/membership/upgrade - Upgrade membership
   - GET /test - Test endpoint

5. MIDDLEWARE:
   - Auth middleware for JWT verification
   - Validation middleware for request validation
   - Error handling middleware

6. DATABASE MODELS:
   - User: name, email, password (hashed), role, timestamps
   - StudentProfile: userId, fullName, avatar, bio, location, 
     membershipTier, socialLinks, timestamps

================================================================================
                        KEY INTEGRATIONS
================================================================================

1. FRONTEND-BACKEND COMMUNICATION:
   - REST API for authentication and profile management
   - WebSocket for real-time code execution

2. CODE EXECUTION FLOW:
   - User writes Java code in the editor
   - Code is sent via WebSocket to backend
   - Backend compiles with javac and runs with java
   - Output is streamed back via WebSocket
   - User sees output in console

3. AUTHENTICATION FLOW:
   - User registers or logs in
   - Backend returns JWT token
   - Token is stored in localStorage
   - Token is sent with each authenticated request
